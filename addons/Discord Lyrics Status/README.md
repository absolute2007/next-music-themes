# Discord Lyrics Status

![Discord Lyrics Status](icon.jpg)

Аддон для [Next Music](https://github.com/Web-Next-Music/Next-Music-Client): текущая строка песни
появляется в статусе твоего профиля Discord, синхронно с музыкой.

- Строки меняются точно в такт: таймер позиции без прыжков и с небольшим упреждением.
- Текст берётся из встроенного модуля Next Music, а если его нет — из [LRCLIB](https://lrclib.net)
  с умным поиском (без feat, remaster и прочих меток в названии).
- В паузе, на проигрышах и после трека возвращается твой обычный статус.
- Если клиент упал или закрылся, статус всё равно восстановится: строка живёт в Discord
  ограниченное время и сама исчезает, а при следующем запуске аддон вернёт сохранённый статус.
- Кнопка настроек встраивается в правую часть плеера, рядом с очередью и громкостью.

## Установка

Одной командой в PowerShell:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/absolute2007/next-music-themes/main/install.ps1))) -Name 'Discord Lyrics Status'
```

Установщик закроет Next Music, положит аддон в `%APPDATA%\next-music\Addons\Discord Lyrics Status`
и запустит клиент снова. Темы аддон не отключает.

Вручную: скопируйте папку `Discord Lyrics Status` в `%APPDATA%\next-music\Addons\` и перезапустите
Next Music.

## Токен Discord

Чтобы менять статус, аддону нужен токен твоего аккаунта Discord. При первом запуске окно
настроек откроется само: вставь токен, аддон проверит его и начнёт работать. Окно потом
открывается кнопкой в плеере.

Токен хранится только у тебя, в локальном хранилище клиента, и отправляется только в Discord.
В коде аддона токена нет. Никому его не показывай: по токену можно войти в аккаунт.

Изменение статуса через пользовательский токен формально нарушает правила Discord
(self-bot). Пользуйся на свой риск.

Чтобы выключить аддон, переименуйте папку в `!Discord Lyrics Status` и перезапустите клиент.
