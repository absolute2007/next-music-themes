# External Sources

Аддон для [Next Music](https://github.com/Web-Next-Music/Next-Music-Client): вкладка
«Сторонние треки» в сайдбаре. Ищет музыку в других сервисах и загружает её в твой аккаунт
Яндекс Музыки как собственные треки. Они играют на всех устройствах, где ты вошёл в аккаунт.

## Источники

| Источник | Настройка | Что внутри |
| --- | --- | --- |
| Bandcamp | не нужна | Независимые артисты и лейблы, полные треки в mp3 128 кбит/с. Треки, у которых артист закрыл прослушивание, добавить нельзя. |
| VK | нужен токен | Музыка твоего аккаунта и общий каталог, полные версии. |
| Zaycev | не нужна | Русскоязычный каталог, с транслитом и подсказками по исполнителям. |
| Internet Archive | не нужна | Свободная и архивная музыка, полные записи. |

Поиск идёт по всем подключённым источникам одновременно, результаты приходят по мере готовности.
Можно выбрать один источник кнопками над списком.

## Как пользоваться

- Нажмите на обложку, чтобы послушать трек до добавления (кроме потоков, которые приходят шифрованными кусками: VK).
- Сердце добавляет трек в «Мне нравится», плюс открывает список плейлистов.
- Одновременно качаются два трека, остальные ждут в очереди. У каждого видно прогресс, при ошибке есть кнопка «повторить».

## Подключение VK

Шестерёнка справа вверху → «Получить токен». Войдите в VK и разрешите доступ, откроется пустая страница.
Скопируйте её адрес целиком, вставьте в поле и нажмите «Проверить и сохранить».
Токен хранится только в локальном хранилище клиента и отправляется только на api.vk.com. Никому его не показывайте.

VK отдаёт музыку только приложению Kate Mobile, и страница сама так представиться не может. Поэтому установщик
ставит фоновый помощник `vk-proxy.cjs`: он работает без окна через сам `Next Music.exe` (отдельный Node не нужен),
слушает только `127.0.0.1:2008`, принимает запросы только со страниц Яндекс Музыки и пересылает их на api.vk.com
с нужным User-Agent. Он запускается сразу после установки и при каждом входе в Windows (ключ
`NextMusic External Sources vk-proxy` в `HKCU\...\Run`). Аддон находит его сам. Если помощник не запущен,
вкладка VK так и скажет.

## Установка

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/tune-music/next-music-themes/main/install.ps1))) -Name 'External Sources'
```

Вручную: скопируйте папку `External Sources` в `%APPDATA%\next-music\Addons\` и перезапустите Next Music.
Нужен вход в аккаунт Яндекс Музыки. Чтобы выключить, переименуйте папку в `!External Sources`.

## Файлы

| `vk-proxy.cjs` | фоновый прокси для API VK |
| `vk-proxy.vbs` | скрытый запуск прокси |
